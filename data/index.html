TTY help

          
        

        

          
Commands

          

            
HELP

            
Show supported TTY commands.

            
PING

            
Check that the command channel is alive. Returns PONG.

            
RUN <profile>

            
Run a saved profile. Repeats are controlled by REPEAT or LOOP blocks inside the macro.

            
STOP

            
Stop the current macro.

            
LINE <macro_line>

            
Run one macro command line without saving a profile.

          


          
Auth

          

            
Access token

            
Required only when TTY password is enabled in Settings.

            
WebSocket log

            
Uses the same token and shows the command log in real time.

          


          
Examples

          
PING
RUN hello
RUN mouse_test
STOP

          
LINE KEY CTRL ALT T
LINE TEXT git status
LINE KEY ENTER

        

      

    

    

      

      

        

          
Macro help

          
        

        

          
Commands

          

            
TEXT / TYPE

            
Print text as keyboard input.

            
DELAY / WAIT

            
Pause for 0..86400000 milliseconds.

            
KEY / HOTKEY

            
Press a key or key combination. Common names and aliases include CTRL, CONTROL, ALT, SHIFT, GUI, WIN, CMD, ENTER, RETURN, ESC, ESCAPE, TAB, BACKSPACE, DELETE, DEL, INSERT and INS.

            
REPEAT / LOOP / END

            
Repeat 1..100000000 times or forever until Stop. Fast loops yield after 64 instructions.

            
MOUSE MOVE

            
Move by X/Y in -32767..32767. Optional third value bends the path into a smooth arc.

            
MOUSE WHEEL / SCROLL

            
Scroll vertically by -10000..10000 signed steps.

            
MOUSE PAN / HWHEEL

            
Scroll horizontally by -10000..10000 signed steps.

            
MOUSE CLICK / PRESS / RELEASE

            
Control LEFT, RIGHT, MIDDLE, WHEEL or MBUTTON mouse button.

            
RELEASEALL

            
Release all keyboard and mouse buttons.

          


          
Comments

          

            
# comment

            
Ignored by the macro engine and kept in profile export/import.

            
; comment

            
Alternative comment syntax.

            
// comment

            
Alternative comment syntax.

          


          
Loops

          

            
REPEAT <count>

            
Run commands until END the selected number of times.

            
LOOP

            
Run commands until END forever. Stop with the Stop button, TTY STOP or GPIO STOP.

            
END

            
Close the nearest REPEAT or LOOP block.

          


          
Examples

          
KEY CTRL ALT T
DELAY 500
TEXT echo HID MacroPad ready
KEY ENTER

          
REPEAT 40
  MOUSE MOVE 30 0 2
  DELAY 120
  MOUSE MOVE 0 30 2
  MOUSE CLICK LEFT
END

          
MOUSE WHEEL -3
DELAY 100
MOUSE WHEEL 3
MOUSE CLICK WHEEL
