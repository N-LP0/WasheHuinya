# GPIO и физические кнопки

GPIO-кнопки запускают сохраненные профили макросов без web UI и TTY. Системная команда `STOP` всегда зарезервирована как GPIO-действие и по умолчанию назначена на `GPIO4`.

## Подключение

Кнопка подключается между выбранным GPIO и общим проводом `GND`.

```text
GPIO ---- кнопка ---- GND
```

Внешний резистор для обычной кнопки не нужен: прошивка включает внутреннюю подтяжку `INPUT_PULLUP`.

Логика входа:

- кнопка отпущена: вход подтянут к `HIGH`;
- кнопка нажата: вход замкнут на `GND`, уровень `LOW`;
- прерывание настроено на `CHANGE`, поэтому прошивка видит и нажатие, и отпускание.

## Поведение макроса

Для GPIO нет режимов `Once`, `Repeat` и `Loop`.

Назначение работает как удерживаемая кнопка:

- при нажатии кнопки запускается назначенный профиль;
- пока кнопка удерживается, профиль повторяется;
- при отпускании кнопки макрос не обрывается посреди профиля, а доходит до последней строки текущего прохода и завершается;
- если нажать вторую GPIO-кнопку, не отпуская первую, вторая кнопка выигрывает;
- макрос первой кнопки останавливается сразу, после чего запускается профиль второй кнопки.

Системная команда `STOP` работает отдельно от профилей:

- `STOP` по умолчанию назначен на `GPIO4`;
- `STOP` можно переназначить на любой разрешенный GPIO через вкладку `GPIO`;
- `STOP` останавливает текущий макрос сразу при нажатии кнопки;
- `STOP` не удаляется из `Assigned GPIO`; кнопку можно только переназначить на другой пин.

Если первая кнопка все еще удерживается после отпускания второй, она не возобновляется автоматически. Для нового запуска ее нужно отпустить и нажать снова.

## Антидребезг

Все кнопки работают через прерывания.

ISR выполняет только минимальную работу:

- проверяет время последнего события;
- отбрасывает повторные фронты внутри окна антидребезга;
- ставит флаг события для FreeRTOS-задачи.

Макрос не запускается внутри ISR. Нажатие и отпускание обрабатываются в `gpioTask`, чтобы не блокировать прерывание и не выполнять файловые операции из ISR.

Текущее окно антидребезга: `12 ms`.

Ожидаемая задержка реакции:

- обычно до `5 ms` на обработку `gpioTask`;
- антидребезг не добавляет задержку к первому валидному событию, а только блокирует дребезг.

## Допустимые пины

Web UI предлагает только сокращенный безопасный список пинов:

```text
GPIO 4
GPIO 5
GPIO 6
GPIO 7
GPIO 8
GPIO 9
GPIO 10
```

Остальные пины намеренно не используются в GPIO-настройках, даже если физически доступны на плате.

Исключены:

- `GPIO0` - boot/strapping pin;
- `GPIO19` и `GPIO20` - USB;
- `GPIO21` - WS2812 RGB LED;
- `GPIO45` и `GPIO46` - strapping pins;
- `GPIO26..37` и соседние системные диапазоны - на ESP32-S3 модулях могут быть связаны с flash/PSRAM или системными линиями;
- `GPIO1..3`, `GPIO11..18`, `GPIO33..44`, `GPIO47..48` - не предлагаются, чтобы снизить риск конфликта с особенностями конкретной платы.

Перед подключением конкретной платы все равно проверь ее pinout: даже разрешенный GPIO может быть не выведен на разъем или использоваться внешней обвязкой.

## Настройка в web UI

Открой вкладку `GPIO`.

Для назначения кнопки выбери:

- `GPIO pin`;
- `Profile / command`.

В поле `Profile / command` можно выбрать сохраненный профиль или системную команду `STOP`. Нажми `Assign`, чтобы сохранить назначение.

Нажми строку в таблице назначений, чтобы вернуть ее параметры в форму.

Нажми `Clear`, чтобы удалить назначение выбранного пина. Системное назначение `STOP` удалить нельзя; для него кнопка `Clear` недоступна.

## API

Сохранить назначение:

```http
POST /api/gpio/save
Content-Type: application/x-www-form-urlencoded

pin=4&profile=admin
```

Переназначить системную команду `STOP`:

```http
POST /api/gpio/save
Content-Type: application/x-www-form-urlencoded

pin=7&profile=STOP
```

Удалить назначение:

```http
POST /api/gpio/delete
Content-Type: application/x-www-form-urlencoded

pin=4
```

Текущие назначения возвращаются в `GET /api/status` в поле `gpioBindings`.

Пример:

```json
{
  "gpioBindings": [
    {
      "pin": 4,
      "profile": "STOP",
      "reserved": true,
      "enabled": true,
      "mode": "stop"
    }
  ]
}
```
