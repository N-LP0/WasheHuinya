# LED-индикация

На плате установлен один адресный RGB-светодиод WS2812, подключенный к `GPIO21`.

Индикация вынесена в отдельный модуль:

- [`include/LedService.h`](../../include/LedService.h)
- [`src/LedService.cpp`](../../src/LedService.cpp)

`RuntimeTasks` выбирает текущий статус программы, а `LedService` отвечает за цвет, яркость и паттерн.

## Принципы

- Яркость намеренно очень низкая, чтобы светодиод не слепил и не добавлял заметный нагрев.
- Постоянный цвет используется для штатных состояний.
- Мигание используется только там, где нужно привлечь внимание: загрузка, подключение к Wi-Fi, BLE pairing и ошибка.
- Управление светодиодом выполняется из FreeRTOS-задачи `ledTask`, без `delay()`.

## Статусы

| Статус         | Цвет       | Паттерн         | Значение                                                         |
| -------------- | ---------- | --------------- | ---------------------------------------------------------------- |
| `Boot`         | белый      | быстро мигает   | Устройство загружается, сервисы еще не готовы.                   |
| `ApOnly`       | желтый     | постоянно горит | Устройство подняло свою точку доступа и не подключено к роутеру. |
| `Connecting`   | синий      | мигает          | Есть сохраненный SSID, идет попытка подключения к Wi-Fi.         |
| `Online`       | зеленый    | постоянно горит | Устройство подключено к Wi-Fi сети.                              |
| `BlePairing`   | голубой    | быстро мигает   | BLE-хост выполняет сопряжение с устройством.                     |
| `BleConnected` | голубой    | постоянно горит | BLE HID подключен к хосту.                                       |
| `Busy`         | фиолетовый | постоянно горит | Выполняется макрос.                                              |
| `Error`        | красный    | мигает          | Ошибка, требующая внимания.                                      |

Приоритет индикации: выполняющийся макрос, BLE pairing, активное BLE-подключение, затем состояние Wi-Fi. Поэтому во время выполнения макроса светодиод остается фиолетовым даже при подключенном BLE-хосте.

## GPIO

WS2812 использует `GPIO21`. Этот пин нельзя назначать под GPIO-кнопки или другие внешние функции.

Пин задается в [`src/Application.cpp`](../../src/Application.cpp):

```cpp
constexpr uint8_t kStatusRgbPin = 21;
```

## Изменение статусов

Цвета и паттерны меняются в [`src/LedService.cpp`](../../src/LedService.cpp).

Чтобы добавить новый статус:

1. Добавь значение в `LedStatus` в [`include/LedService.h`](../../include/LedService.h).
2. Добавь цвет в [`src/LedService.cpp`](../../src/LedService.cpp).
3. Добавь обработку в `LedService::colorFor()`.
4. Если статус должен мигать, добавь его в `LedService::shouldBlink()` и выбери период в `LedService::blinkPeriodMs()`.
5. Установи новый статус из `RuntimeTasks`.
